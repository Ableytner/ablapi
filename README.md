# ablapi

Ableytners' general-purpose REST API.

## Overview

This project is a collection of small API (Application Programming Interface) endpoints serving various uses.

It is structured into two types of submodules:
* Core: General-purpose endpoints
* Specific: Self-contained endpoints for a specific project

## Development environment setup

If you want to contribute to this project, you need to set up your local environment.

### Clone the repository

Run the command
```bash
git clone https://github.com/Ableytner/ablapi
cd ablapi
```
in your terminal.

### Install .NET runtime

This project was written for .NET Core 10.0, which needs to be [installed](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) to develop locally.

All used NuGet-packages are available on the official NuGet server.
